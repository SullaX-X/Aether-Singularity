# 🪐 Aether & Singularity — Интерактивный астрономический атлас

Образовательный интерактивный веб-атлас и путеводитель смены научных парадигм для планетариев, лекториев и любителей астрономии.

---

## 🌟 Главы атласа

1. **Глава 1 · Эпициклы и компромисс Тихо Браге** — Геоцентрическая модель Птолемея, гелиоцентризм Коперника и гео-гелиоцентрический компромисс Браге с интерактивной симуляцией ретроградного движения Марса.
2. **Глава 2 · Сито планет (МАС 2006)** — Фотографический архив Земли, Ганимеда, Цереры и Плутона, 3 строгих правила планеты, симуляция расчистки орбиты и история открытия Эриды.
3. **Глава 3 · Млечный Путь и Тёмная Материя** — Реалистичные ракурсы диска («Сверху» и «Изнутри» вдоль экватора), интерактивная 3D-модель галактики на Three.js (80 000 звёзд), волны плотности Лина — Шу, кривая вращения Веры Рубин, логарифмическая шкала масштабов Вселенной ($10^0$ – $10^{21}$ м) и космическая аудиодорожка.
4. **Глава 4 · Гравитация и Горизонт Событий** — Эйнштейновское гравитационное линзирование, аккреционный диск и релятивистское замедление времени возле чёрной дыры.
5. **Словарь астрономических терминов** — Интерактивный глоссарий терминов МАС с фильтрацией по категориям и адаптивным поиском.

## 🚀 Развёртывание на GitHub Pages

Проект полностью оптимизирован и готов к работе на **GitHub Pages**:

1. **Относительный базовый путь (`base: './'`)**: В `vite.config.ts` настроен относительный базовый путь, поэтому проект работает как на корневом домене (`username.github.io`), так и в подпапках репозиториев (`username.github.io/repository-name/`).
2. **Файл `.nojekyll`**: Создан в каталоге `public/`, что исключает фильтрацию ассетов со стороны сборщика Jekyll на GitHub.
3. **Маршрутизация `404.html`**: Предотвращает ошибку 404 при обновлении страниц и прямых переходах на GitHub Pages.
4. **Оптимизация бандла (Code Splitting)**:
   - Библиотека `three` вынесена в отдельный кэшируемый чанк `vendor-three`.
   - Анимационный движок `motion` вынесен в `vendor-motion`.
   - Иконки `lucide-react` вынесены в `vendor-icons`.
5. **Автоматический CI/CD Workflow**: Файл `.github/workflows/deploy.yml` автоматически собирает проект и деплоит его на GitHub Pages при каждом пуше в ветку `main` или `master`.

### Как включить GitHub Pages в репозитории:
1. Зайдите в ваш репозиторий на GitHub.
2. Откройте **Settings** → **Pages**.
3. В разделе **Build and deployment** выберите **Source**: **GitHub Actions**.
4. При следующем коммите/пуше проект автоматически соберется и опубликуется!

## 🛠️ Локальный запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (порт 3000)
npm run dev

# Проверка типов (TypeScript)
npm run lint

# Сборка production-бандла для GitHub Pages
npm run build

# Предпросмотр собранного проекта
npm run preview
```
